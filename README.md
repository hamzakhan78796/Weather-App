# 🌤️ Modern Weather Application (Laravel)

A sleek, responsive, and feature-rich Weather Application built with PHP Laravel, featuring dynamic atmospheric backgrounds, glassmorphism UI, real-time forecasts, and location-based weather tracking.

---

## ✨ Key Features

* Dynamic Atmospheric Backgrounds: Background gradients automatically shift based on weather conditions (Clear, Clouds, Rain, Thunderstorm, Snow).
* Glassmorphism UI Design: Modern translucent frosted-glass aesthetic styled with Tailwind/Custom CSS.
* Hourly & 5-Day Forecast: Detailed breakdown of upcoming hourly temperatures and multi-day forecasts with smooth horizontal scrolling.
* Search History & Quick Tags: Keeps track of recently searched cities with quick-access tags and clear history options.
* Unit Conversion: Easily toggle between Celsius (°C) and Fahrenheit (°F).
* Dark Mode Support: Fully integrated dark mode for comfortable viewing in low-light environments.
* Fully Responsive: Optimized seamlessly for both desktop and mobile viewports.

---

## 🛠️ Tech Stack

* Backend: PHP, Laravel Framework
* Frontend: Blade Templates, HTML5, CSS3 / Modern Flexbox & Grid
* Styling: Custom Glassmorphic CSS, Responsive Media Queries
* Version Control: Git & GitHub

## 🚀 Getting Started Locally

To run this project on your local machine, follow these steps:

1. Clone the repository:
   git clone https://github.com/hamzakhan78796/Weather-App.git

2. Navigate to the project directory:
   cd Weather-App

3. Install PHP dependencies:
   composer install

4. Setup environment file:
   cp .env.example .env
   php artisan key:generate

5. Run the local development server:
   php artisan serve

6. Open your browser and visit: http://127.0.0.1:8000
